# Assess production readiness

[Prompts](../PROMPTS.md) · [Usage](../README.md#using-a-prompt)

**Use:** Read-only; no release authority.

```text
Inspect candidate-bound local/CI/preview evidence, exact artifact, configuration, migrations, access controls and findings.

Assess compatibility, rollout order, monitoring and recovery across persistent data/external services. Prior application build alone restores no database. Identify cost/data/destructive approvals and accepted exceptions.

Return ready/blocked, evidence and bounded release/recovery plan. Verify artifact identity beyond moving branch names. No deployment, migration, merge or permission changes; assessment grants no approval.
```
