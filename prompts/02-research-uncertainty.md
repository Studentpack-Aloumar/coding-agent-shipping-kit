# Resolve uncertainty

[Prompts](../PROMPTS.md) · [Usage](../README.md#using-a-prompt)

**Use:** External fact affects implementation.

```text
Check dependency version and existing code. Resolve the blocking uncertainty using primary publisher docs and existing search/browser. Exa/Context7 optional; no redundant retrieval or installation without need.

For reuse decisions, inspect saved recipes; search relevant whole products, starters, packages, services and website references. Compare up to three credible options by required journeys, total adoption/upkeep effort, license, maintenance, host and cost. Name choice, rejections and remaining work; distinguish source review from runtime proof. Stop when evidence supports the decision. Preserve existing architecture for scoped tasks.

Return decision, primary links, applicable version/date, uncertainty and code/test consequence. Separate facts from inference; explain material source conflicts. Stop when supported.

No code edits or private code, credentials, patient/customer data in public queries.
```
