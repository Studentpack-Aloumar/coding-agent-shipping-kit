# Prompt library

[Home](README.md) · [Usage](README.md#using-a-prompt) · [Gates](GATES.md)

Choose one; copy its block or explicitly request the attached file. Reuse context/authorization. Scope stays explicit: read-only review grants no repair authority. These 19 prompts register no commands.
